# omni-widget-test
Тестовая страница web-виджета Омни

Страница загружает SDK со стабильным параметром `omni_loader=revalidate-v1`.
Он позволяет один раз обойти старую копию SDK, сохранённую браузером по прежнему
адресу. При следующих загрузках используется тот же адрес: сервер должен отдавать
SDK с `Cache-Control: no-cache` и ETag, чтобы браузер проверял актуальность версии.
Версия адреса `test-page.js` в HTML обновлена вместе с этим изменением.

Для проверки обновите страницу обычной кнопкой браузера, нажмите «Проверить
подключение», затем «Загрузить виджет» и откройте чат. Инкогнито и ручная очистка
кеша не нужны. В уже открытом чате код не заменяется: после обновления SDK нужно
перезагрузить саму страницу.
